### Module 1 – HTML Fundamentals

- **HTML structure**  
  Learned the basic HTML skeleton with `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, and `<body>` to define a valid web page.  
- **Content elements**  
  Practiced using headings `<h1>–<h6>`, paragraphs `<p>`, line breaks `<br>`, and lists with `<ul>`, `<ol>`, and `<li>` to organize content.  
- **Text formatting**  
  Used `<b>` and `<i>` for visual styling, and `<strong>` and `<em>` for semantic emphasis, preferring semantic tags for accessibility and SEO.  
- **Links and images**  
  Created hyperlinks with `<a href="...">` and displayed images using `<img src="..." alt="...">` including basic attributes like width and height.
